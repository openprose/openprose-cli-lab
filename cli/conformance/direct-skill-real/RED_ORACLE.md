# Direct-skill real lane red oracle

This lane is red until a provider-free fake proves that every trial:

- invokes Prime noninteractively with one explicit legacy skill while ambient
  skills, extensions, context files, sessions, prompt templates, and themes are
  disabled;
- starts in a fresh directory containing an exact, pre-created
  `.prose/.env` with legacy telemetry disabled;
- has a controlled `PATH` on which no `prose` executable resolves, and records
  no attempted OpenProse CLI or legacy telemetry invocation;
- enforces frozen trial, cost, time, process-output, and workspace limits;
- retains only bounded redacted evidence, file metadata/digests, tool-name
  counts, and effect assertions—never credentials, provider prompts, or raw
  transcripts; and
- cannot award current-skill, semantic, Prose Complete, interactive-TUI, or
  release claims from an old-skill observation.

Real calls are forbidden until the policy, matrix, programs, and provider-free
tests are frozen and green.
